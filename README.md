
# UMMA University Management App

## About the Project
The UMMA University Management App is an Android-based application designed to provide a centralized platform for accessing university services.

The application supports four user roles: Students, Lecturers, Administrators, and Support Staff.

## Main Features

### Student
- View academic units
- View results and GPA
- Access lecture timetables
- View examination information
- Access university services

### Lecturer
- View assigned courses
- View class lists
- Access attendance information
- Manage academic activities

### Administrator
- Manage user accounts
- View departments and courses
- Manage academic information
- Access university reports

### Support Staff
- Access help desk services
- View student welfare information
- Access campus facilities
- View support contacts

## Technologies Used
- Kotlin
- XML
- Android Studio
- Room Database
- SQLite

## Application Design
The application uses a professional university design with blue, white, and gold colours.

## Installation
1. Download the APK from the Releases section.
2. Install the APK on an Android device.
3. Open the application.
4. Register a demonstration account or log in with an existing account.

## Project Structure
- `app/` - Application source code
- `data/` - Database entities, DAO and database configuration
- `res/layout/` - XML user interface layouts

## Important Note
This project is an academic prototype. Some university service modules display sample information and are not yet connected to a live university management system.
